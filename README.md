# 🗂️ Dedupe Finder

A command-line tool that finds duplicate files by comparing their actual content — not just their filenames — and safely quarantines the extras so you can reclaim disk space without risking accidental deletion.

## Why I built this

My photos and documents folders had years of accumulated duplicates — the same picture saved from a text, a download, and a backup, all with different filenames, all quietly eating up space. I wanted something that could tell me *exactly* which files were true duplicates (not just similarly named) and give me the space back — without me having to trust an automated tool to delete anything permanently.

## How it works

1. Scans a folder and all its subfolders
2. Groups files by size first (fast, cheap check)
3. For files that share a size, compares their actual content using a SHA-256 hash — this is the same technique used to verify file integrity, so it's effectively impossible for two different files to produce a false match
4. Reports every duplicate group found and how much space you'd reclaim
5. Optionally moves the extra copies into a `duplicates_found` folder — **nothing is ever permanently deleted by this tool.** You review the quarantine folder yourself and delete for real only when you're confident.

## Getting started (no terminal experience needed)

### 1. Install Python
This script needs Python installed on your computer.

- Go to [python.org/downloads](https://www.python.org/downloads/)
- Download and run the installer for your OS
- **On Windows**: during install, check the box that says **"Add Python to PATH"** — easy to miss, but important
- To confirm it worked, open a terminal  and type `python3 --version` (Mac/Linux) or `python --version` (Windows) — it should print a version number

### 2. Open a terminal
- **Mac**: open Spotlight (Cmd+Space), type "Terminal", hit Enter
- **Windows**: press the Start key, type "Command Prompt" or "PowerShell", hit Enter
- **Linux**: you know where it is

### 3. Download this project
- Click the green **Code** button on this repo → **Download ZIP**
- Unzip it somewhere you'll remember, like your Desktop

### 4. Navigate to the folder in your terminal
In the terminal, type `cd ` (with a space after it), then drag the unzipped folder into the terminal window — it'll auto-fill the path. Hit Enter.

### 5. Run the script
Do a **dry run** first — this only reports what it finds, nothing is moved:

```bash
python3 dedupe.py --path "/path/to/folder/you/want/to/check"
```
*(On Windows, use `python` instead of `python3`)*

Replace the path with the actual folder you want scanned — you can drag a folder into the terminal window the same way as step 4 to get its path automatically.

Once you've reviewed the results and you're ready to actually free up space:

```bash
python3 dedupe.py --path "/path/to/folder" --quarantine
```

This moves duplicates into a new `duplicates_found` folder for you to review and delete manually.

## Options

| Flag | What it does |
|---|---|
| `--path` | Folder to scan (required) |
| `--quarantine` | Actually move duplicates, instead of just reporting them |
| `--quarantine-dir` | Custom location for quarantined files (default: `./duplicates_found`) |
| `--min-size` | Skip files smaller than this many bytes, e.g. `--min-size 10240` for 10KB |
| `--skip` | Comma-separated folder names to skip, on top of the defaults, e.g. `--skip old_backups,temp` |
| `--no-default-skips` | Turn off the built-in skip list entirely (see below) |

### Why some folders are skipped by default

Folders like `venv`, `node_modules`, `.git`, `.gradle`, and `.godot` are generated by package managers and build tools — they naturally contain thousands of tiny identical files (license copies, install metadata, cached build artifacts) that "look like" duplicates but are actually required for a project to run correctly. Moving files out of these folders can break a working project.

By default, this tool skips folders with these names anywhere in the scan:

```
venv, .venv, env, node_modules, .git, .gradle, .godot, __pycache__,
.idea, .vs, .vscode, dist, build, .next, .cache, .mypy_cache, .pytest_cache
```

If you actually want to see inside these folders too, run with `--no-default-skips`.

## Tech notes

Pure Python, no external dependencies — uses only the standard library (`hashlib`, `os`, `shutil`, `argparse`). Duplicate detection is two-pass: files are first grouped by size (cheap), and only files sharing a size are actually hashed and compared, which keeps large folders fast instead of hashing every single file up front.
